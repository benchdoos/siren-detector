# API Siren Detector

Эта страница описывает HTTP API приложения и WebSocket-интерфейс. Это API
управления/выдачи данных, а не контракт подключаемого источника, обработчика
или выходного адаптера. Целевые границы этих компонентов описаны в
[API компонентов](component-api.md); текущая и целевая схемы — в
[архитектуре](architecture.md).

REST API обслуживается тем же сервером, что и веб-интерфейс. Для работающего экземпляра интерактивная документация FastAPI доступна по адресу `http://<хост>:8080/docs`, OpenAPI JSON — `http://<хост>:8080/openapi.json`. OpenAPI автоматически строится по REST-маршрутам приложения. WebSocket-маршруты в OpenAPI не входят и описаны ниже.

Если включена авторизация (`AUTH_ENABLED` в `hub/.env`), защищённые запросы должны содержать токен, который проверяется приложением как viewer или admin. Чтение обычно требует viewer, а изменение настроек, запись обратной связи и управление калибровкой — admin. Публичные исключения: `/api/auth/status`, `/api/auth/check`, загрузка клипа и аудио калибровки; проверяйте фактическую конфигурацию развёртывания. При отключённой авторизации права не ограничиваются токеном.

## Основные REST-маршруты

| Метод и путь | Доступ при включённой авторизации | Назначение |
|---|---|---|
| `GET /api/auth/status` | Публичный | Сообщает, включена ли авторизация. |
| `POST /api/auth/check` | Публичный | Проверяет токен из JSON-тела `{"token":"…"}`. |
| `GET /api/settings` | Viewer | Текущие настройки, defaults и доступность DSP-модели. |
| `GET /api/runtime/status` | Viewer | Состояние аудиоподписчиков, глубина очередей, пропуски и ошибки callback. |
| `GET /metrics` | Viewer | Prometheus 0.0.4: состояние движков, аудиоочередей и выходов. |
| `GET /api/engines/manifests` | Viewer | Manifests локально зарегистрированных решений. |
| `GET /api/engine-graph` | Viewer | Сохранённый граф и доступность настроенных решений. |
| `PUT /api/engine-graph` | Admin | Проверяет и сохраняет конфигурацию `engine-graph.v1`. |
| `POST /api/settings` | Admin | Обновляет переданные поля настроек; неверные типы, диапазоны и режимы возвращают `400`. |
| `POST /api/settings/reset` | Admin | Сбрасывает настройки к defaults. |
| `GET /api/sources` | Viewer | Состояние известных аудиоисточников и пользовательские имена. |
| `GET /api/metrics` | Viewer | Метрики валидации, если они смонтированы. |
| `GET /api/audits` | Viewer | Последние аудиты модели и датасета. |
| `GET /api/calibrate` | Viewer | Состояние фоновой калибровки. |
| `POST /api/calibrate` | Admin | Начинает фоновую калибровку; точная схема доступна в Swagger UI. |
| `POST /api/calibrate/stop` | Admin | Останавливает и сохраняет текущую калибровку. |
| `POST /api/calibrate/cancel` | Admin | Отменяет калибровку. |
| `GET /api/calibrate/recordings` | Viewer | Список записей калибровки. |
| `DELETE /api/calibrate/recordings` | Admin | Удаляет записи калибровки. |
| `GET /calibrate-audio/{source_name}/{filename}` | Viewer-токен в query или Authorization | Загружает аудиозапись калибровки. |
| `GET /calibrate-audio/{source_name}/{filename}/spectrogram` | Нет проверки на маршруте | Спектрограмма записи калибровки. |
| `POST /feedback` | Admin | Присваивает клипу метку; тело содержит `filename` и `label`. |
| `POST /feedback/segments` | Admin | Сохраняет разметку сегментов клипа. |
| `POST /api/manual-event` | Admin | Создаёт событие вручную с записью клипа. |
| `GET /clips/{filename}` | Viewer-токен в query или Authorization | Получает WAV-клип. |
| `GET /clips/{filename}/spectrogram` | Нет проверки на маршруте | Получает спектрограмму клипа. |

Защищённые маршруты при неверном или отсутствующем токене возвращают `401` либо `403`. Поля настроек и их диапазоны приведены в [справочнике настроек](settings.md).

`GET /api/runtime/status` возвращает `available`, массив `components` и массив
`subscribers`. Компонент содержит `component_id`, `name`, `version`, `state`,
`started_at`, `updated_at`, `error_count` и `last_error`. Для каждой аудиоподписки
доступны `subscriber_id`, `state`, `queue_depth`,
`queue_capacity`, `overflow`, счётчики `frames_received`, `frames_processed`,
`frames_dropped`, `sequence_gaps`, `callback_errors` и `last_error`. Это статус
движка и доставки кадров. YAMNet также передаёт сюда ошибки parallel inference
workers; произвольные фоновые потоки стороннего плагина должны сообщать свои
сбои через `runtime.set_component_state(component_id, "degraded", error)`.
Жёсткий timeout и принудительное прерывание Python callback не поддерживаются.

`GET /api/engines/manifests` показывает локально зарегистрированные решения.
`GET/PUT /api/engine-graph` читают и сохраняют конфигурацию графа, сохраняя
неизвестные поля для совместимости. Сохранённый граф активируется после
перезапуска детектора и задаёт движки и маршруты источников. При активном графе
явный `--engine` запрещён, чтобы не было двух источников выбора движков.

## WebSocket

### `/ws`

Подключение: `ws://<хост>:8080/ws` (или `wss://` за TLS-прокси). Сначала сервер отправляет `{"type":"session","started_at":...}`, затем последний снимок оценок и доступную историю событий; далее передаёт обновления из шины событий. Маршрут не проверяет токен.

### `/ws/audio`

Подключение: `ws://<хост>:8080/ws/audio`; сервер передаёт бинарные аудиоданные float32 PCM. Необязательный параметр `?source_id=<ID>` ограничивает поток одним источником. При включённой авторизации требуется viewer-токен; при отказе соединение закрывается кодом `4401`.

## Источник спецификации

FastAPI публикует OpenAPI на работающем сервере через `/openapi.json`, Swagger UI — через `/docs`. Схема автоматически отражает REST-контракты. Используйте OpenAPI целевой версии для точных форм запросов, ответов и ошибок.
