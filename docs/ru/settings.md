# Настройки Siren Detector

Настройки детектора доступны в веб-интерфейсе по кнопке **Settings** и через `/api/settings`. Изменения применяются сразу после сохранения и записываются в `/clips/settings.json` (в Docker — в томе `clips`). Кнопка сброса восстанавливает значения по умолчанию из `detector/config.py`.

## Режимы обработки

Параметр `detection_mode` управляет обработкой нескольких активных аудиоисточников:

| Значение | Поведение | Когда использовать |
|---|---|---|
| `round_robin` (по умолчанию) | Один цикл последовательно обрабатывает источники. | Меньше пиковая нагрузка CPU; подходит для маломощного хоста. |
| `parallel` | Для источников работают отдельные циклы инференса. | Меньше ожидание отдельного источника; выше расход CPU и памяти. |

Распознавание выполняется на хосте Detector, а не на ESP32. `inference_interval_seconds` задаёт интервал между проходами по источнику: `0.25–2.0` с, по умолчанию `0.5`. Больший интервал снижает нагрузку, но может увеличить задержку и вероятность пропустить короткий звук.

## Пороги распознавания

| Настройка | По умолчанию | Допустимый диапазон | Назначение |
|---|---:|---:|---|
| `siren_threshold` | `0.10` | `0–1` | Минимальная оценка сирены для срабатывания. При активной MLP применяется к выходу MLP. Снижение повышает чувствительность и число ложных срабатываний. |
| `explosion_threshold` | `0.15` | `0–1` | Порог классов YAMNet Explosion, Burst/pop и Gunshot/gunfire. |
| `uav_threshold` | `0.15` | `0–1` | Порог класса Motorcycle, используемого как приближение к звуку двигателя БПЛА. |
| `yamnet_min_gate` | `0.01` | `0–1` | Минимальная оценка YAMNet, необходимая для доверия прогнозу MLP сирены. `0` отключает эту проверку. |

## DSP-предфильтр

Опциональная DSP-модель может пропускать запуск YAMNet, когда уверенно распознаёт фон. Файлы модели должны присутствовать в каталоге моделей; наличие показывается в настройках и `/api/settings`. Настройки можно переопределить для каждого источника.

| Настройка | По умолчанию | Диапазон | Назначение |
|---|---:|---:|---|
| `dsp_enabled` | `1` (включён) | `0–1` | Включает предфильтр; при отсутствии файлов модели он недоступен. |
| `dsp_bg_threshold` | `0.92` | `0.5–1` | Уверенность в фоне для пропуска YAMNet. Более высокое значение осторожнее пропускает окна. |
| `dsp_bg_release_threshold` | `0.90` | `0.5–1` | Если уверенность фона падает ниже этого значения, YAMNet снова запускается. |
| `dsp_bg_confirm_windows` | `2` | `1–10` | Число последовательных окон фона перед началом пропусков. |
| `dsp_max_consecutive_skips` | `20` | `0–200` | Максимум последовательных пропусков до принудительного прохода YAMNet; `0` отключает ограничение. |
| `dsp_event_gate` | `0.30` | `0–0.5` | Если вероятность класса события выше этого порога, YAMNet запускается несмотря на оценку фона. `0` отключает этот шлюз. |

`dsp_source_overrides` — объект с настройками по ID источника. Веб-интерфейс позволяет включить или отключить DSP и задать индивидуальные значения порогов для каждого источника; неуказанные значения наследуются от общих.

## Сглаживание и события

| Настройка | По умолчанию | Диапазон | Назначение |
|---|---:|---:|---|
| `possible_triggers` | `4` | `1–60` | Число окон выше порога для раннего статуса «возможно». |
| `confirmed_triggers` | `8` | `1–60` | Число окон выше порога для подтверждения события, сохранения клипа и публикации события. Рекомендуется значение больше `possible_triggers`. |
| `smoothing_window_seconds` | `30` | `5–120` | Длительность скользящего окна оценок, в котором учитываются срабатывания. |
| `cooldown_seconds` | `60` | `0–600` | Пауза после подтверждения события, чтобы не создавать дубликаты. `0` отключает паузу. |
| `refractory_seconds` | `15` | `0–120` | После паузы детектор ждёт снижения оценки перед повторным срабатыванием; по истечении времени снова готов к событию. `0` отключает ожидание. |

## Очистка импульсных щелчков

Фильтр заменяет короткие импульсные выбросы интерполированными значениями перед инференсом. Для каждого источника доступны переопределения через `click_removal_source_overrides`.

| Настройка | По умолчанию | Диапазон | Назначение |
|---|---:|---:|---|
| `click_removal_enabled` | `1` (включено) | `0–1` | Включает удаление коротких щелчков. |
| `click_removal_threshold` | `10.0` | `3–50` | Порог выброса в MAD; меньшее значение фильтрует агрессивнее. |
| `click_removal_max_width` | `5` | `1–20` отсчётов | Максимальная длина группы импульсов для удаления; более длинные сигналы сохраняются. |

## Источники

| Настройка | Тип | Назначение |
|---|---|---|
| `disabled_sources` | список ID | Отключённые источники не создают события, хотя аудио продолжает приниматься. |
| `source_custom_names` | объект `ID → имя` | Пользовательские имена источников в интерфейсе. |

Настройки источника, DSP и фильтра щелчков доступны на вкладке Sources. Данные источника доступны через [`GET /api/sources`](api.md).

## Аудиоклипы и разметка

| Настройка | По умолчанию | Диапазон | Назначение |
|---|---:|---:|---|
| `clip_seconds` | `10` | `5–60` с | Длина клипа подтверждённого события. Буфер в памяти увеличивается при изменении значения. |
| `clip_from_possible` | `0` (выключено) | `0–1` | При включении сохраняет клип от раннего статуса с двумя секундами предбуфера, вместо последних N секунд до подтверждения. |
| `user_event_clip_seconds` | `15` | `5–60` с | Длина клипа при ручном создании события. |
| `save_background_segments` | `false` | `true/false` | Сохраняет неразмеченные промежутки как примеры фонового звука при разметке сегментов. |

## Обновление настроек через API

Получите текущие значения и defaults через `GET /api/settings`. Измените только нужные поля запросом `POST /api/settings` с JSON-объектом и правами администратора. Например:

```json
{"siren_threshold": 0.12, "detection_mode": "round_robin"}
```

Допустимые диапазоны проверяются сервером. Сброс выполняется через `POST /api/settings/reset`. Полное описание маршрутов находится в [справочнике API](api.md).
