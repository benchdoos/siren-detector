# Аппаратная сборка

## ESP32-S3 и INMP441

Аудиоузел использует плату ESP32-S3 с одним или двумя MEMS-микрофонами INMP441. Прошивка собирается через ESPHome и прошивается по USB или OTA.

### Список компонентов

| Компонент | Кол-во | Примечания |
|---|---:|---|
| Плата ESP32-S3 (N16R8 или аналог) | 1 | Нужен PSRAM для ESPHome; большинство N16R8 подходят. |
| Модуль INMP441 | 1–2 | Второй микрофон опционален; улучшает SNR примерно на 3 дБ при усреднении. |
| Керамический конденсатор 100 нФ | 1 на микрофон | Между VDD и GND, как можно ближе к микрофону. Снижает импульсные помехи. |
| Провода-перемычки | ~6 на микрофон | Для макетирования. |
| USB-C кабель | 1 | Для первой прошивки; дальше OTA по Wi-Fi. |

### Подключение

Каждый INMP441 подключается к своей I2S шине на ESP32-S3. Прошивка поддерживает два микрофона; второй опционален.

**Микрофон 1** (I2S шина 0):

| Пин INMP441 | GPIO ESP32-S3 | Назначение |
|---|---:|---|
| SCK (BCLK) | GPIO4 | Тактовый сигнал |
| WS (LRCLK) | GPIO5 | Выбор канала |
| SD (DOUT) | GPIO6 | Данные |
| L/R | GND | Левый канал (на землю) |
| VDD | 3.3 V | |
| GND | GND | |

**Микрофон 2** (I2S шина 1, опционально):

| Пин INMP441 | GPIO ESP32-S3 | Назначение |
|---|---:|---|
| SCK (BCLK) | GPIO15 | Тактовый сигнал |
| WS (LRCLK) | GPIO16 | Выбор канала |
| SD (DOUT) | GPIO17 | Данные |
| L/R | GND | Левый канал |
| VDD | 3.3 V | |
| GND | GND | |

Провод MCLK не нужен — INMP441 генерирует внутренний тактовый сигнал от BCLK.

### Установка конденсатора

Керамический конденсатор 100 нФ (0.1 мкФ) ставится между VDD и GND непосредственно на выводах модуля микрофона. Без него INMP441 более подвержен импульсным помехам по питанию, которые проявляются как щелчки в аудио. В детекторе есть фильтр удаления щелчков, но чистое железо решает проблему у источника.

### Как работают два микрофона

Когда оба микрофона подключены, прошивка усредняет их сэмплы в один SDR1-поток (source ID `0`). Это улучшает отношение сигнал/шум примерно на 3 дБ. Второй микрофон **не** появляется как отдельный источник в детекторе — это один смешанный поток.

Если второй микрофон отключён или молчит (RMS ниже 0.0001), прошивка отправляет только данные первого микрофона. Изменений в настройках не требуется.

### Питание и размещение

- INMP441 работает от 1.8–3.3 В. Используйте выход 3.3 В платы ESP32-S3.
- Провода между микрофоном и ESP32 должны быть короткими — длинные провода ловят наводки на линиях I2S.
- Микрофон монтируется звуковым портом в сторону прослушиваемой зоны. В корпусе порт должен оставаться открытым.
- INMP441 передаёт 24-битный звук в 32-битных I2S слотах. Прошивка сдвигает вправо на 8 бит и нормализует к 24-битному диапазону перед отправкой.

## Прошивка

1. Скопируйте `esp32/secrets.yaml.example` в `esp32/secrets.yaml` и заполните данные Wi-Fi и IP хоста Hub:

   ```yaml
   wifi_ssid: "ВашSSID"
   wifi_password: "ВашПароль"
   ap_password: "пароль-фоллбэка"
   udp_target_ip: "192.168.1.100"
   udp_target_port: "9000"
   ```

2. Первая прошивка — подключите ESP32-S3 по USB:

   ```bash
   esphome run esp32/siren-detector.yaml
   ```

   Выберите COM-порт при запросе.

3. Последующие обновления через OTA (USB не нужен):

   ```bash
   esphome run esp32/siren-detector.yaml --device siren-detector.local
   ```

   Или `make deploy-firmware` — копирует конфиг на RPi и компилирует/прошивает там.

Устройство включает `microphone_capture` через 5 секунд после загрузки и начинает отправлять SDR1/UDP пакеты на указанный адрес Hub.

### Резервная точка доступа

Если настроенная Wi-Fi сеть недоступна, ESP32 создаёт точку доступа "Siren Detector Fallback" с паролем из `secrets.yaml`. Подключитесь к ней и используйте captive portal по адресу `192.168.4.1` для настройки Wi-Fi.
