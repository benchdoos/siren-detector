# Siren Detector

Открытый проект для некоммерческого обнаружения сирен гражданского оповещения, взрывов и звуков приближающегося мотоцикла как приближения к звуку БПЛА. Аудиоузел на ESP32-S3 передаёт звук с микрофонов на Linux-хост, где детектор анализирует его и показывает события в веб-интерфейсе и, при желании, публикует их через MQTT.

> [!WARNING]
> Проект и все его компоненты предназначены исключительно для мирных целей. Военное, вредоносное или разрушительное использование запрещено.

## Что находится в репозитории

- **Прошивка ESP32** получает звук с INMP441 и передаёт его по UDP.
- **Hub** пересылает аудиопакеты детектору и, при необходимости, рекордеру.
- **Detector** запускает YAMNet и дополнительный обученный для проекта MLP, ведёт состояние событий для каждого источника и предоставляет веб-интерфейс и API.
- **Инструменты датасета и ML** помогают записывать, размечать и расширять данные, обучать и оценивать классификаторы.

Текущий сценарий — удалённое распознавание: ESP32 получает и передаёт звук, а модель работает на Linux-хосте, например Raspberry Pi. Автономное распознавание непосредственно на ESP32 — направление развития, но пока не текущий режим.

## Параметры проекта

- Частота дискретизации: 16 кГц, моно.
- Транспорт: UDP с заголовком пакета SDR1.
- Порты по умолчанию: Hub `9000`, рекордер `9001`, UDP детектора `9002`, веб-интерфейс `8080`.
