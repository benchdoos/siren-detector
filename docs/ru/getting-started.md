# Начало работы

## Что понадобится

- ESP32-S3 и один микрофон INMP441 (второй микрофон необязателен).
- Linux-хост с Docker Compose; основной сценарий развёртывания описан для Raspberry Pi.
- Установка ESPHome для сборки и прошивки устройства.
- Сетевой доступ ESP32 к хосту, на котором работает Hub.

## 1. Настройте проект

Из корня репозитория:

```bash
cp .env.example .env
cp hub/.env.example hub/.env
cp esp32/secrets.yaml.example esp32/secrets.yaml
```

Укажите адрес целевого хоста и UDP-порт в файле секретов ESPHome. В корневом `.env` задайте SSH-адрес и URL веб-интерфейса, если собираетесь пользоваться командами развёртывания из Makefile. Эти два файла решают разные задачи: корневой файл настраивает команды Make, а `hub/.env` — Docker Compose.

Не добавляйте в Git реальные пароли Wi-Fi, токены администратора и другие секреты.

## 2. Прошейте ESP32

Скопируйте `esp32/siren-detector.yaml` и свой `secrets.yaml` на хост с ESPHome. Проверьте конфигурацию, соберите прошивку и прошейте устройство через ESPHome. Схема подключения микрофонов описана в разделе [Несколько микрофонов](multi-microphone.md).

## 3. Запустите Hub и detector

На Linux-хосте выполните в каталоге развёртывания:

```bash
cd hub
docker compose up -d hub detector
```

Hub принимает звук ESP32 на UDP-порту `9000` и пересылает пакеты детектору на `9002`. Веб-интерфейс детектора доступен на порту `8080`.

Откройте `http://<адрес-хоста>:8080`. При первом запуске файлы модели YAMNet загружаются и кэшируются; для этого нужен доступ к сети и время на первоначальную загрузку.

## 4. Проверьте передачу аудио

Убедитесь, что ESP32 в сети и отправляет пакеты, затем проверьте статус источника и аудио в веб-интерфейсе. Логи развёртывания можно смотреть командой `make logs` из настроенной рабочей копии или командой `docker compose logs -f hub detector` на хосте.

## Локальная разработка

Detector можно запускать напрямую через Python. Установите зависимости из `detector/requirements.txt`, затем выполните `python -m detector.main`; UDP-порт по умолчанию — `9000`, веб-порт — `8080`. Если отдельно запускается Hub, настройте UDP-порт детектора на `9002`, как в `hub/docker-compose.yml`.
