Siren Detector / Settings

Detection Mode
Detection Mode
Determines how the engine processes audio from multiple sources. Switches on the fly after Save.
Round Robin — one thread processes sources in turn. Lower peak CPU use.

Parallel — one inference thread per source. Sources are processed simultaneously, which can increase peak CPU use.
Default: round_robin
Inference Interval
Time between model passes for each audio source. Larger values reduce CPU load but can delay detections or miss shorter sounds.
Range: 0.25 – 2.0 sec
Default: 0.5
Thresholds

Minimum confidence score for each sound type. When MLP classifier is active (siren), this applies to the MLP output score.

Siren Threshold
MLP confidence score required for a siren detection to count as a trigger. Lower = more sensitive but more false positives.
Range: 0.0 – 1.0
Default: 0.10
Explosion Threshold
YAMNet confidence for explosion/gunshot/burst. Classes: Explosion, Burst pop, Gunshot gunfire.
Range: 0.0 – 1.0
Default: 0.15
UAVs Threshold
YAMNet confidence for UAV engine sounds.
Range: 0.0 – 1.0
Default: 0.15
DSP Pre-filter

Lightweight Conv1D model that skips YAMNet for confident background, saving CPU.

DSP Pre-filter
When On, a lightweight DSP classifier pre-screens audio before YAMNet. Confident background is skipped, reducing CPU load by up to 90%. Disable to always run full YAMNet inference.
Default: On
DSP Background Threshold
Minimum DSP confidence to skip YAMNet. Higher = more conservative (fewer skips, less risk of missing events). Lower = more aggressive (more skips, saves more CPU).
Range: 0.50 – 1.00
Default: 0.85
DSP Background Release Threshold
While DSP is skipping YAMNet, it resumes YAMNet when background confidence drops below this value. Higher values release background sooner; lower values keep skipping longer.
Range: 0.50 – 1.00
Default: 0.85
DSP Background Confirm Windows
Number of consecutive confident background predictions required before DSP starts skipping YAMNet. Higher values prevent it from returning to background too quickly but run YAMNet more often.
Range: 1 – 10 windows
Default: 2
DSP Event Gate
If any event class (siren, explosion, uav) has DSP probability above this threshold, always run YAMNet even if background confidence is high. Lower = more sensitive, catches quieter events. Set to 0 to disable.
Range: 0.00 – 0.50
Default: 0.08
DSP Max Consecutive Skips
After this many consecutive DSP skips for a source, force one YAMNet pass. Low values (3-5) let YAMNet catch events quickly despite DSP's slow 5s window. Higher values save more CPU but delay detection. Set to 0 to disable.
Range: 0 – 200
Default: 4 (~2 seconds)
Click Removal

Suppresses impulse noise (clicks, pops) from INMP441 before inference. Prevents false "Explosion" detections from electrical interference.

Click Removal
When On, detects impulse noise (1-5 sample spikes from electrical interference) and replaces them with interpolated values before YAMNet inference. Real explosions span hundreds of samples and are not affected.
Default: On
Click Removal Threshold
How many median absolute deviations a sample must exceed to be classified as a click. Lower = more aggressive removal (may clip loud sounds). Higher = only catches extreme spikes.
Range: 3.0 – 50.0
Default: 10.0
Max Click Width
Maximum number of consecutive outlier samples to treat as a click. Groups longer than this are left untouched (likely real audio). INMP441 clicks are typically 1-5 samples.
Range: 1 – 20 samples
Default: 5
MLP Gate

Controls when to trust the MLP classifier for siren detection.

YAMNet Min Gate
YAMNet must show at least this score for the MLP result to be trusted. Prevents MLP hallucinations on unfamiliar audio. Set to 0 to fully trust MLP.
Range: 0.0 – 1.0
Default: 0.01
Trigger Counts

How many above-threshold inference windows are needed to change detection state.

Possible Triggers
Windows needed for early warning (yellow badge). No clip saved yet.
Range: 1 – 60
Default: 4
Confirmed Triggers
Windows needed to confirm event. Saves clip, sends MQTT. Must be > possible triggers.
Range: 1 – 60
Default: 8
Timing
Smoothing Window
Rolling time window for trigger accumulation. 30s window at 0.5s inference = up to 61 slots.
Range: 5 – 120 sec
Default: 30
Cooldown
After confirmed event, ignore detections for this long. Prevents duplicate events. 0 = no cooldown.
Range: 0 – 600 sec
Default: 60
Refractory
After cooldown, wait for score to drop before re-arming. If score stays high, expires by timeout. 0 = disabled.
Range: 0 – 120 sec
Default: 15
Audio Clips

Saved when an event is confirmed. Used for review and retraining.

Clip Length
Duration of saved audio clip. Shorter = less noise for retraining.
Range: 5 – 60 sec
Default: 10
Clip From Possible
When On, clip captures from the moment event reaches "possible" (+ 2s pre-buffer) instead of last N seconds before "confirmed". Includes per-window scores in metadata.
Default: Off
User-Created Events
User Event Clip Length
Duration saved when you create an event manually.
Range: 5 – 60 sec
Default: 15
Save Background Segments
When audio segments are labeled, save the remaining unmarked parts as background training data.
Default: Off

Background Calibration

Record ambient background from a microphone so the model learns what is not a siren through this audio source.

How to get best results:
• Record 5+ minutes of your typical environment
• Include varied sounds: appliances, street noise, conversations, 3D printers, etc.
• Record multiple sessions at different times of day
• Each source (ESP32 mic, USB mic) needs its own calibration
• After recording, run make retrain to apply

Universal audio event detection platform. ESP32-S3 captures audio from an INMP441 microphone and streams it to a detection engine powered by YAMNet + MLP.

Target classes: siren, explosion, UAVs, background.
