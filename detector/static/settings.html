Siren Detector / Settings

Thresholds

Minimum confidence score for each sound type. When MLP classifier is active (siren), this applies to the MLP output score.

Siren Threshold
MLP confidence score required for a siren detection to count as a trigger. Lower = more sensitive but more false positives.
Range: 0.0 – 1.0
Default: 0.10
Explosion Threshold
YAMNet confidence for explosion/gunshot/burst. Classes: Explosion, Burst pop, Gunshot gunfire.
Range: 0.0 – 1.0
Default: 0.15
Motorcycle Threshold
YAMNet confidence for motorcycle engine sounds.
Range: 0.0 – 1.0
Default: 0.15
MLP Gate

Controls when to trust the MLP classifier for siren detection.

YAMNet Min Gate
YAMNet must show at least this score for the MLP result to be trusted. Prevents MLP hallucinations on unfamiliar audio. Set to 0 to fully trust MLP.
Range: 0.0 – 1.0
Default: 0.01
Trigger Counts

How many above-threshold inference windows are needed to change detection state.

Possible Triggers
Windows needed for early warning (yellow badge). No clip saved yet.
Range: 1 – 60
Default: 4
Confirmed Triggers
Windows needed to confirm event. Saves clip, sends MQTT. Must be > possible triggers.
Range: 1 – 60
Default: 8
Timing
Smoothing Window
Rolling time window for trigger accumulation. 30s window at 0.5s inference = up to 61 slots.
Range: 5 – 120 sec
Default: 30
Cooldown
After confirmed event, ignore detections for this long. Prevents duplicate events. 0 = no cooldown.
Range: 0 – 600 sec
Default: 60
Refractory
After cooldown, wait for score to drop before re-arming. If score stays high, expires by timeout. 0 = disabled.
Range: 0 – 120 sec
Default: 15
Audio Clips

Saved when an event is confirmed. Used for review and retraining.

Clip Length
Duration of saved audio clip. Shorter = less noise for retraining.
Range: 5 – 60 sec
Default: 10
Clip From Possible
When On, clip captures from the moment event reaches "possible" (+ 2s pre-buffer) instead of last N seconds before "confirmed". Includes per-window scores in metadata.
Default: Off
Audio Sources

Enable or disable detection for each microphone. Disabled sources still receive audio (available for calibration) but their events are discarded.

Background Calibration

Record ambient background from a microphone so the model learns what is not a siren through this audio source.

How to get best results:
• Record 5+ minutes of your typical environment
• Include varied sounds: appliances, street noise, conversations, 3D printers, etc.
• Record multiple sessions at different times of day
• Each source (ESP32 mic, USB mic) needs its own calibration
• After recording, run make retrain to apply

Universal audio event detection platform. ESP32-S3 captures audio from an INMP441 microphone and streams it to a detection engine powered by YAMNet + MLP.

Target classes: siren, explosion, motorcycle, background.
