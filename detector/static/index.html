Detection Thresholds
Detection Thresholds · Siren
Minimum confidence score for a siren detection to count as a trigger. Lower values catch more sirens but increase false positives. When MLP is active, this applies to the MLP score (gated by YAMNet min gate).
Range: 0.0 – 1.0
Default: 0.10
Detection Thresholds · Explosion
Minimum YAMNet confidence for explosion/gunshot/burst sounds. Covers classes: Explosion, Burst pop, Gunshot gunfire.
Range: 0.0 – 1.0
Default: 0.15
Detection Thresholds · Motorcycle
Minimum YAMNet confidence for motorcycle engine sounds.
Range: 0.0 – 1.0
Default: 0.15
Temporal Smoothing
Temporal Smoothing · Possible Triggers
Number of above-threshold windows within the smoothing window needed to enter "possible" state. This is the early warning — the UI shows a yellow badge but no clip is saved yet.
Range: 1 – 60
Default: 4
Temporal Smoothing · Confirmed Triggers
Number of above-threshold windows needed to confirm an event. A confirmed event saves an audio clip, sends MQTT notification, and shows a red badge. Must be greater than possible triggers.
Range: 1 – 60
Default: 8
Temporal Smoothing · Window
Rolling time window (in seconds) over which trigger counts are accumulated. Inference runs every 0.5s, so a 30s window holds up to 61 slots. Larger window = more tolerant to intermittent sounds, but slower to react.
Range: 5 – 120 sec
Default: 30
Temporal Smoothing · Cooldown
After a confirmed event, ignore all detections for this many seconds. Prevents duplicate events from the same prolonged sound. Set to 0 for no cooldown (useful for testing).
Range: 0 – 600 sec
Default: 60
Temporal Smoothing · Refractory
After cooldown ends, the detector waits up to this many seconds before allowing re-trigger. If the score drops below threshold during this period, the refractory ends immediately (the sound stopped). If the score stays high, the refractory expires by timeout — allowing re-detection of a new/ongoing event. Set to 0 to disable refractory entirely.
Range: 0 – 120 sec
Default: 15
MLP Gate
MLP Gate · YAMNet Min Gate
When MLP classifier is active for siren detection, YAMNet must show at least this score for the MLP result to be trusted. Prevents MLP false positives when YAMNet sees no siren-like sound at all. Set to 0 to fully trust MLP regardless of YAMNet opinion — may increase false positives but catches sirens that YAMNet misclassifies as silence.
Range: 0.0 – 1.0
Default: 0.01
Clip
Clip · Length
Duration of audio clip (in seconds) saved when an event is confirmed. Shorter clips contain less background noise for retraining. Applies immediately.
Range: 5 – 60 sec
Default: 10
Clip · From Possible
By default clip captures the last N seconds before confirmed. When On, clip starts from the moment event reaches possible (+ 2s pre-buffer), capturing the actual sound wave that triggered detection. Per-window scores are saved in clip JSON metadata for precise labeling during retraining.
Default: Off

Detection Status

Score bar — real-time confidence from the model (YAMNet or MLP). Color changes at threshold.

State badge — current detector state:

  idle — no activity
  possible — threshold exceeded several times, early warning
  confirmed — event confirmed, clip saved
  cooldown — ignoring detections after confirmed event
  refractory — waiting for sound to stop before re-arming

Triggers — N/Xp/Yc — current trigger count / needed for possible / needed for confirmed. Triggers accumulate when score exceeds threshold within a rolling time window.

Cooldown — seconds remaining until detector re-arms after a confirmed event.

Refractory — after cooldown, waits for score to drop below threshold (or timeout) before allowing new detections.

Each detector (siren, explosion, motorcycle) has its own independent counters and timers.
