Открытый проект для обнаружения сирен гражданского оповещения, взрывов и звуков приближающегося мотоцикла. ESP32-S3 получает аудио, Linux-хост выполняет распознавание и показывает события в веб-интерфейсе, а при необходимости — передаёт их через MQTT.

## Быстрый запуск

Понадобятся ESP32-S3 с микрофоном INMP441, Linux-хост с Docker Compose и установленный ESPHome.

1. Настройте окружение и секреты устройства:

   ```bash
   cp .env.example .env
   cp hub/.env.example hub/.env
   cp esp32/secrets.yaml.example esp32/secrets.yaml
   ```

   Укажите адрес хоста и учётные данные в соответствующих файлах.

2. Скопируйте `esp32/siren-detector.yaml` и `secrets.yaml` на хост с ESPHome, проверьте конфигурацию, соберите и прошейте устройство.
3. Запустите Hub и detector на Linux-хосте:

   ```bash
   cd hub
   docker compose up -d hub detector
   ```

4. Откройте `http://<адрес-хоста>:8080`. При первом запуске YAMNet загрузится и сохранится в кэше.

Подробности о развёртывании, настройках, MQTT и переобучении — в [документации](docs/ru/index.md). Для локального просмотра полной документации на двух языках установите зависимости из `docs/requirements.txt` и выполните `mkdocs serve`.

## Структура проекта

- `esp32/` — прошивка ESPHome и получение звука.
- `hub/` — UDP-ретранслятор и развёртывание через Docker Compose.
- `detector/` — распознавание, API, веб-интерфейс и интеграции.
- `audio_source/`, `recorder/` — передача звука с USB-микрофона и запись аудио.
- `dataset/`, `ml/` — подготовка данных, обучение и оценка моделей.
- `docs/` — документация на двух языках.
